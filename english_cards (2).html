Готов учить?

Введи API ключ Google Sheets, загрузи таблицу, настрой параметры слева и нажми «Начать сессию».

Google Sheets — настройка

Шаги в Google Cloud Console:

  1. Включи Google Sheets API (APIs & Services → Library)
  2. Credentials → API key — для чтения. API restrictions → только Sheets API
  3. Credentials → OAuth client ID — для записи. Тип: Web application. В Authorized JavaScript origins добавь http://localhost:8000 (или порт, на котором открываешь файл)
  4. Открой сайт через локальный сервер: python3 -m http.server 8000 в папке с файлом
  5. Таблицу: Share → Anyone with link → Viewer
ID берется из ссылки: docs.google.com/spreadsheets/d/ID/edit
